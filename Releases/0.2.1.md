## Play

Extract the whole package. Use `TowerDefense.exe` for explicit guest sign-in, or the private Steam test launcher with Steam already signed in. Mac uses `TowerDefense.app` and the existing unsigned-build instructions in MAC_TESTING.md. Use matching 0.2.1 packages and separate devices/accounts; Steam and EOS guests remain separate pools. Two copies under one Windows account must use LAN / THIS PC, not the same EOS device identity.

Both players Ready. WASD moves; right-drag orbits the hero-centered camera. Select the weapon with the wheel/hotbar and hold left mouse to attack toward the ground cursor. T opens sends; U opens XP upgrades. Panels block local movement/attacks but do not pause the match. Host Pause/Results can Reset to Lobby.

## Added

- One Raider, free send every 1.5 seconds, +5 match XP; one 25-XP upgrade for future sends. Maximum 16 troops per lane.
- Sword/staff attacks with stamina/mana costs; staff is currently an instant narrow ray, not a traveling projectile. Attacks only target incoming troops on your own lane.
- One starter tower per technology group, defender gold on kills, 300-HP castles, victory/draw and results/rematch.
- Seven-second ghost timer: roam your own half, retain economy and manage XP upgrades; no attack/collection/vision eligibility. Ghost sending defaults off pending owner choice. Respawn restores starter health/energy at home; existing towers continue defending.
- Host-validated commands with round/sequence duplicate protection, private owner-readable energy/economy and pooled local lane visuals driven by spawn time rather than per-frame troop transform packets.

## Verification and limits

110/110 EditMode tests, Windows two-process combat/controls/ghost/results/reset/rejoin/rejection regression, paired packaging and Mac static checks passed. Ghost/results automation used explicit development fixtures; final balance, sustained load and internet latency/loss were not measured. See DEVELOPMENT_LOG.md for exact evidence and the corrected initial diagnostic failure.

Gold cannot yet be spent; purchased land, harvesting, build recipes, invasion/fog, loot/crafting, permanent progression, public queues/parties/team modes, movement prediction and replacement-host/reconnect recovery are not implemented. Disconnect still resets the lobby; host loss ends the session. Zero ghost vision eligibility is groundwork, not actual network fog filtering.

Friend combat in 0.2.1 and actual Mac launch/security/input/native/peer verification remain open, especially EOS Mac/Windows. Mac is unsigned/unnotarized. Steam App ID 480 is explicit development testing only, not production distribution. Player-hosted authority is not a trusted competitive rewards server. No paid service billing was enabled.
