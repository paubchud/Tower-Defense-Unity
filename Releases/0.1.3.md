# Tower Defense 0.1.3 - Experimental Windows/Mac Steam Playtest

New **Mac compatibility test**, with a matching Windows build. Public experimental prerelease only, **not production Steam distribution**. Mac launch/render/input/Steam native loading and real two-account Windows/Mac internet gameplay remain unverified until the friend test. No combat/economy content was added.

## Download and launch

1. Under **Assets**, download **TowerDefense-0.1.3-Windows.zip** for Windows 64-bit, or **TowerDefense-0.1.3-macOS.zip** for Mac. Do not choose the source-code ZIP. Extract the whole archive; Unity and GitHub collaborator access are not required.
2. Sign into Steam. Windows: open **Start-Private-Steam-Test.cmd**. Mac: read the included **MAC_TESTING.md**, then open **TowerDefense.app**, choose a class and enable **Private Steam Test (480)**. The `.command` launcher is optional.
3. Both friends must use **0.1.3**, separate Steam accounts/devices and the same test mode. One hosts, copies/shares the numeric room code privately; the other joins. Both Ready. Keep the host's game open. Older 0.1.2 and legacy Relay 0.1 cannot join this build.

## Mac test notice

- Universal Mono build includes Intel and Apple Silicon player/Unity/Steam binaries, targeting macOS 12+ and Metal. Built on Windows; no Mac runtime pass is claimed.
- This prototype is **not Developer ID signed or notarized**. macOS may block it. Only approve this specific app through macOS's own per-app approval if you trust the download. Do not disable Gatekeeper globally. Stop/report damage, malware or signature errors; do not force the app through security failures.
- ZIP metadata preserves executable permissions. Use Finder to extract and keep the complete app together. See [Mac testing instructions](https://github.com/paubchud/Tower-Defense-Unity/blob/codex/macos-playtest/MAC_TESTING.md) for security notes, test checklist and log location.

## Limits and feedback

Steam development mode uses Valve's shared **Spacewar App ID 480**, not our production identity. Lobbies remain friends-only/two-player. Prefer room codes; both should already be running this game before an invite, or Steam may launch Spacewar. The host computer simulates the match; host migration and dedicated game servers are not implemented.

WASD moves; right-drag orbits around the hero; wheel/hotbar selects starter gear. B/U/T/I open placeholders/equipment; Esc opens the menu without pausing multiplayer. This is still the movement/lobby foundation: no sent troops, combat, working towers, currencies, harvesting, ghost respawn, progression or guest internet/login/saves yet. Guest-ready architecture remains; EOS is canceled and no paid backend was enabled.

Report Mac chip/macOS version, game version, host/client role, network setup and exact errors via [GitHub Issues](https://github.com/paubchud/Tower-Defense-Unity/issues). Review/redact logs first; never post private room codes, Steam IDs, passwords or tokens. Actual Mac runtime and separate-account/device Steam tests must pass before gameplay Step 2 (0.2).
