# Tower Defense 0.1 - Step 1 network prototype

Download **TowerDefense-0.1-Windows.zip**, extract the entire ZIP, and run **TowerDefense.exe**. Windows 64-bit; no Unity, GitHub, Steam, or player account required.

## Play with a friend

1. Both players use this same version. Click Play and choose Warrior or Wizard.
2. One player clicks Host Online and shares the room code privately.
3. The other enters the code and clicks Join Online. Both click Ready.
4. Keep the host's game open. No router port forwarding is needed for online rooms.

For two copies on one PC, choose LAN / This PC and join 127.0.0.1, port 7777. For different PCs on a LAN, use the host's LAN IPv4 address and allow the game through the private-network firewall if prompted.

## Included

- Main menu, class selection, two-player ready lobby, and guest online room codes.
- 3D blockout arena with two straight lanes and Warrior/Wizard starter equipment.
- WASD movement, hero-centered camera, right-mouse drag orbit, mouse-wheel hotbar selection.
- B/U/T/I management placeholders, Esc pause menu, leave/reset/rehost handling.
- Two-player limit and server-authoritative movement/class/item selection.

This is an early connectivity prototype, not a complete tower-defense game. Attacks, troops, functional towers, harvesting, currencies, ghost respawn, victory, and saved progression are not implemented yet.

Online play in **0.1 still uses Unity Relay** with anonymous guest authentication. Itch-first Epic Online Services guest/P2P integration is planned, not included. Steam integration is not required or implemented. The current Relay service has quotas; this release does not establish a permanent unlimited free hosting guarantee.

The arena and menu are intentionally placeholder art. Test validation uses standalone peers on one PC; two separate homes/machines, latency/loss, and production-scale performance are not yet verified. Some unused URP postprocessing shaders may log warnings without affecting the prototype's scene/UI.
