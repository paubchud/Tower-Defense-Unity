# Tower Defense 0.1.2 - Experimental Steam Playtest

Public development-test download, **not a production Steam release**. Two-account/device Steam gameplay and separate-home reachability still need testing. This is the movement/lobby foundation, not a complete tower-defense game.

## Download and launch

1. Under **Assets**, download **TowerDefense-0.1.2-Windows.zip**. Do not download GitHub's source-code ZIP. Windows 64-bit only; Unity is not required.
2. Extract the **whole ZIP** to a folder. Keep the executable, data folder, DLLs and launcher together.
3. Open Steam and sign into your own account. Your opponent needs a separate Steam account/device; be Steam friends.
4. Run **Start-Private-Steam-Test.cmd** in the extracted folder. The launcher name refers to the friends-only development-test mode; the ZIP download itself is public.
5. Select **Play** and Warrior or Wizard. One player selects **Host Steam**, then **Copy Room Code**. Share that code privately; the other player enters it and chooses **Join Steam**. Both press **Ready**. Keep the host's game open.

Alternatively, run `TowerDefense.exe` and select **Enable Private Steam Test (480)** after choosing a class. Both players must use version 0.1.2 and enable the test mode.

## Important test limitations

- Explicit development mode borrows Valve's shared **Spacewar App ID 480**. Steam may display Spacewar. This is not our game's production Steam identity or a Steam store/depot release.
- Prefer room codes. Both players should already have this game open before accepting an invite, or Steam may launch the actual Spacewar app. The overlay can be unavailable for direct launches.
- Lobbies remain friends-only and limited to two players. Publishing this ZIP does not add public matchmaking or change lobby privacy.
- The host PC runs the match; this is not a dedicated match server hosted by Valve. Host loss ends the connection; host migration is not implemented.
- No guest internet play, persistent saves, purchases, progression, combat, troop sending, functioning towers/economy, or victory loop yet. Do not use this prototype for sensitive data or trusted competitive rewards.
- The older stable **v0.1** download uses Unity Relay, not Steam; it cannot join this version.

## Controls

- WASD: move. Hold right mouse and drag: orbit the hero-centered camera.
- Mouse wheel/hotbar click: select a starter item.
- B/U/T/I: shop/upgrade/troop placeholders and equipment information. Esc: menu; multiplayer is not paused.
